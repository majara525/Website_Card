# سجل التغييرات

## غير منشور

- اختبار أجهزة فعلية من عدة شركات.
- توقيع نسخة إصدار رسمية ونشرها في متجر مناسب.

## 0.2.0 — 2026-07-29

### أضيف

- موقع تنزيل عربي ونسخة ويب قابلة للتثبيت والعمل دون اتصال.
- رابط APK ثابت باسم `reminders.apk`.
- خيار تثبيت نسخة الويب على آيفون وآيباد مع توضيح حدودها.
- تكرار مستمر دون نطاق زمني.
- وقت تكرار مخصص وتاريخ/ساعة بدء.
- تنبيه مبكر.
- نطاقات زمنية مختلفة حسب اليوم.
- بحث وفرز تصاعدي وتنازلي.
- فئات افتراضية ومخصصة مع أيقونات.
- مفضلة وصفحة مستقلة لها.
- شاشة عرض منفصلة عن التعديل.
- خيارات كتابة القوائم ومربعات المهام والترقيم التلقائي.
- صورة وملف صوتي كمرفقات.
- اختيار الصوت وشدة التذكير.
- المكان أو السياق.
- شاشة تحليلات محلية.
- إعدادات ألوان وتباين وعدد عناصر الويدجت.
- سؤال «تم لهذه المرة أم إيقاف نهائي».
- معالجة مساحات أشرطة النظام.
- أيقونة جديدة للتطبيق.
- إجراءات GitHub للبناء ونشر الموقع.
