# تذكيراتي

تطبيق عربي أصلي لأندرويد مع نسخة ويب قابلة للتثبيت والعمل دون اتصال. صُمّم المشروع ليكون قابلًا للتعديل والتحديث، مع اسم ثابت لملف التنزيل:

```text
reminders.apk
```

عند إصدار نسخة جديدة استبدل الملف نفسه فقط؛ لا تغيّر الاسم ولا تحذف رابط التحميل من الموقع.

## التحميل السريع

- ملف أندرويد الثابت: `downloads/reminders.apk`
- رابط الموقع: `https://mycard.almahad-alali.com/reminders/`
- صفحة الموقع: `index.html`
- تطبيق الويب: `app.html`
- دليل رفع GitHub: `docs/GITHUB_UPLOAD.md`
- دليل النشر: `docs/DEPLOYMENT.md`
- حدود نسخة الويب: `docs/LIMITATIONS.md`

## وظائف تطبيق أندرويد

- تذكير لمرة واحدة.
- تكرار مستمر من تاريخ وساعة محددين، دون نافذة زمنية.
- تكرار ضمن نطاق زمني يومي، بما في ذلك النطاقات التي تتجاوز منتصف الليل.
- نطاق مختلف لكل يوم محدد.
- مدة تكرار مخصصة بالدقائق.
- تنبيه مبكر قبل الموعد.
- إيقاف وتشغيل وحذف وتعديل.
- شاشة عرض للتذكير دون فتح التعديل.
- سؤال عند الضغط على «تم»: لهذه المرة أو إيقاف نهائي.
- بحث في العنوان والملاحظات والفئة والمكان.
- ترتيب حسب وقت التنبيه، العنوان، تاريخ التعديل أو الفئة؛ تصاعدي أو تنازلي.
- مفضلة بنجمة وصفحة مستقلة للمفضلة.
- فئات افتراضية بأيقونات: شخصي، طعام، أدوات، أساسيات، تسوق، صحة، عمل، دراسة، منزل واتصالات.
- إضافة فئات مخصصة مع أيقونة.
- مكان أو سياق للتذكير.
- ملاحظات بقائمة نقطية، مربعات مهام وترقيم تلقائي 1، 2، 3.
- صورة وملف صوتي/تسجيل كمرفقات.
- اختيار صوت التذكير.
- شدة خفيفة أو متوسطة أو قوية.
- تحليلات محلية: عدد التذكيرات، الإنجاز، ساعة الإضافة المعتادة ومتوسط وقت الإنجاز.
- ويدجت يعرض من عنصر واحد إلى خمسة عناصر.
- ألوان ويدجت: فاتح، داكن، تباين عالٍ أو أحمر.
- استعادة المواعيد بعد إعادة التشغيل أو تحديث التطبيق أو تغيير الوقت والمنطقة الزمنية.
- واجهة عربية واتجاه من اليمين إلى اليسار وأسماء أشهر عربية.
- معالجة مساحة شريط الحالة والتنقل في أعلى وأسفل الهاتف.
- تخزين محلي دون حساب أو اتصال بالإنترنت.

## نسخة الويب

الموقع وتطبيق الويب لا يستخدمان مكتبات أو خطوطًا أو خدمات خارجية. بعد الزيارة الأولى يحفظ عامل الخدمة الملفات المطلوبة للعمل دون اتصال.

تتضمن نسخة الويب:

- إنشاء وتعديل وحذف وتشغيل التذكيرات.
- الأنواع الثلاثة الأساسية.
- بحث وفرز وفئات ومفضلة.
- قوائم ومربعات مهام وترقيم في الملاحظات.
- تحليلات محلية.
- تصدير واستيراد نسخة احتياطية بصيغة JSON.
- إشعارات أثناء بقاء الصفحة مفتوحة.
- تثبيت على أندرويد أو آيفون/آيباد كاختصار مستقل.

تنبيهات الويب الخلفية ليست بديلًا كاملًا لتنبيهات أندرويد الأصلية. راجع `docs/LIMITATIONS.md`.

## فتح المشروع وبناؤه

المتطلبات:

- Android Studio.
- JDK 17 أو أحدث.
- Android SDK 36.
- جهاز أندرويد 7.0 أو أحدث.

أوامر PowerShell:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

المخرج الداخلي:

```text
.build/app/outputs/apk/debug/app-debug.apk
```

بعد البناء استبدل ملف التنزيل الثابت:

```text
downloads/reminders.apk
```

## الترقية دون فقد البيانات

لا تغيّر `applicationId` وهو:

```text
com.almahadali.reminders
```

لكل إصدار:

1. زد `versionCode` في `app/build.gradle`.
2. حدّث `versionName`.
3. شغّل الاختبارات والبناء وAndroid Lint.
4. ثبّت الملف الجديد فوق النسخة القديمة وتأكد من بقاء التذكيرات.
5. استبدل `downloads/reminders.apk` مع إبقاء الاسم نفسه.
6. حدّث `CHANGELOG.md` و`docs/UPGRADE_TRACKER.md`.
7. ارفع الملفات نفسها إلى GitHub؛ لا تغيّر اسم APK.
