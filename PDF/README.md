# ماسح المستندات

تطبيق PWA لمسح المستندات وتحويلها إلى ملفات PDF. يعمل بالكامل على جهاز المستخدم، ويدعم العمل بدون اتصال بعد أول زيارة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية.

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## المزايا

- واجهة عربية كاملة واتجاه RTL.
- كاميرا مباشرة لالتقاط صفحات المستند.
- اكتشاف حدود المستند وتصحيح المنظور باستخدام OpenCV.js عند توفره.
- قص يدوي عبر مقابض الزوايا.
- تحسين جودة تلقائي وتحكم يدوي بالسطوع والتباين.
- تدوير الصفحة يمينًا ويسارًا.
- إضافة حتى 20 صفحة.
- ترتيب الصفحات أو حذفها قبل إنشاء PDF.
- إنشاء PDF باستخدام `pdf-lib` مع نص metadata:
  `تم إنشاؤه بواسطة المعهد العالي - شبكة كلّيات قُطرية`
- حفظ محلي، مشاركة، بريد إلكتروني، وطباعة.
- تخزين المستندات السابقة محليًا باستخدام IndexedDB.
- Service Worker وmanifest لجعل التطبيق قابلًا للتثبيت والعمل دون اتصال.

## الخصوصية

كل المعالجة تتم 100% داخل المتصفح. لا يتم رفع الصور أو ملفات PDF إلى أي خادم إلا إذا اختار المستخدم المشاركة صراحة.
